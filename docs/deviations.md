| DEV-001 | Desktop Runtime Execution (Tauri 2 Rust binary + PyInstaller onedir exe) | The Arena workspace runs Linux x64 and has no local Rust/Cargo toolchain or Windows desktop session, so it cannot launch the installed Tauri app or perform a real Windows shell-crash test. | CI run `43428431657` passed Windows and Ubuntu validation, including Rust tests/builds, the Windows frozen-sidecar handshake/EOF smoke, NSIS build and silent install, installed resource path, and post-install IPC smoke. This validates the automated package path, but it does not exercise killing the actual desktop process; runtime acceptance is not claimed. | Complete `docs/manual_windows_runtime_check.md` on Windows 10/11 using the CI artifact, record that the sidecar process tree is gone within 5 seconds after force-terminating the app, and retain non-sensitive evidence. |
| DEV-002 | Python Scientific Stack (`numpy`, `scipy`, `statsmodels`, `arch`, `scikit-learn`, `torch`, `mapie`, `sqlglot`) | Container Python 3.10.12 has standard library only (`sqlite3`, `json`, `unittest`, etc.) without external pip wheels. | `sidecar/energybaseline/sql/guard.py` uses `sqlglot.parse` when installed and falls back to a verified lexical/structural AST validator.
